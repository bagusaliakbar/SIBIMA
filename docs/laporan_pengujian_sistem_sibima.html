Pengujian Keamanan & Kerentanan Web (OWASP Compliance)

ANTI-IDOR ACCESS GATEKEEPER

Naskah skripsi di storage/app/private/ tidak dapat diakses via URL publik. Otorisasi controller menolak akses mahasiswa lain dengan kode HTTP 403 Forbidden.

ANTI-SQL INJECTION

100% kueri database menggunakan PDO Prepared Statements. Injeksi payload SQL ' OR 1=1 -- ditangani aman sebagai string biasa.

ANTI-XSS & ANTI-CSRF

Blade otomatis meng-escape entitas HTML karakter berbahaya. Seluruh form mutasi dilindungi token @csrf dengan masa berlaku sesi aman.

ANTI-SSRF & WEB SERVER GUARD

UrlSecurity memblokir alamat IP loopback dan IP privat. File .htaccess 5-lapisan memblokir berkas .env, .git, dan eksekusi PHP pada subfolder.

Pengujian Aksesibilitas WCAG 2.1 AA & Tipografi Inter

Kontras Warna WCAG AA

Seluruh token semantik (Brand Orange, Emerald, Amber, Rose) memiliki rasio kontras > 4.5:1 terhadap latar Light maupun Dark Mode.

Angka Tabular Presisi

Aturan CSS font-variant-numeric: tabular-nums menjamin digit angka pada NPM, NIDN, tanggal, dan nilai ujian sejajar secara vertikal.

Responsivitas Lintas Layar

Teruji optimal pada resolusi ponsel 360px, tablet 768px, hingga desktop 1920px dengan fitur sidebar collapsible.
