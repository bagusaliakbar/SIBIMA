Laporan Audit & Analisis Mendalam UI/UX Sistem SIBIMA

Secara keseluruhan, antarmuka SIBIMA (Sistem Informasi Bimbingan Mahasiswa) telah memiliki fondasi visual yang sangat kuat dan modern dengan mengadopsi filosofi Clean Enterprise SaaS (setara dengan antarmuka produktivitas modern seperti Linear, Vercel, dan TailwindUI). Penggunaan tipografi Inter dengan angka tabular (tabular-nums), palet semantik berbasis Orange-600 & Slate, serta pola 2-Tier Table Toolbar memberikan kejelasan hierarki data yang sangat baik. Dokumen ini membedah 10 temuan spesifik (UX-01 s.d. UX-10) untuk meningkatkan kematangan UI/UX dari 86.5 (Grade A-) menuju 96+ (Grade A+) tanpa risiko merusak logika backend.

3. Apresiasi Kekuatan Desain Saat Ini (Best Practices yang Sudah Berjalan)

Wajib Dipertahankan

1. Collapsible Sidebar + Peek-on-Hover

Transisi 280px ↔ 80px di layouts/app.blade.php dilengkapi persistensi localStorage dan fitur hover-expand tanpa menggeser konten utama.

2. Actionable Notification Center

Dropdown lonceng notifikasi memungkinkan mahasiswa mengklik "Akan Hadir" atau "Izin" langsung dari dalam kartu notifikasi beserta toggle efek suara.

3. Pola 2-Tier Table Toolbar

Halaman jadwal seminar & sidang memisahkan aksi utama (Simulasi, Import, Tambah) di Tier 1 dan filter/pencarian h-10 serta ekspor PDF/Word di Tier 2.

4. Filter "Hanya Jadwal Saya" untuk Dosen

Tombol pill mandiri yang dapat dikombinasikan dengan tab Mendatang, Hari Ini, dan Riwayat beserta penanda peran otomatis (Ketua Sidang / Penguji).

5. WebKit Autofill Dark Mode Override

Masalah klasik kotak input Chrome yang berubah kuning/putih saat autofill di Dark Mode sudah diatasi tuntas menggunakan inset box-shadow #0f172a.

6. Tipografi Inter + Angka Tabular

Penerapan font-variant-numeric: tabular-nums menjaga kesejajaran vertikal NPM, NIP, tanggal, dan nilai ujian di seluruh tabel data.

4. Temuan Audit UI/UX Mendalam & Solusi Perbaikan (UX-01 s.d. UX-10)

10 Temuan Terverifikasi
[UX-01] Komponen Blade Dasar Warisan Laravel Breeze Belum Selaras dengan Design Token SIBIMA
HIGH • Design System
Lokasi: resources/views/components/primary-button.blade.php, secondary-button.blade.php, modal.blade.php, layouts/navigation.blade.php
Masalah & Dampak UX Saat Ini Komponen <x-primary-button> masih memakai bg-gray-800 dark:bg-gray-200 focus:ring-indigo-500 rounded-md, serta <x-modal> memakai bg-gray-800 rounded-lg. Hal ini bertabrakan dengan identitas SIBIMA (bg-orange-600 rounded-xl & slate-900 rounded-2xl).
Rekomendasi Perbaikan Senior UI/UX Perbarui primary-button.blade.php ke token bg-orange-600 hover:bg-orange-700 text-white rounded-xl h-10 px-4 text-xs font-bold shadow-sm, dan secondary-button / modal ke palet slate dengan sudut rounded-2xl.
[UX-02] Penghapusan Focus Outline Global (outline: none !important) Tanpa Pengganti :focus-visible pada Button
HIGH • Accessibility WCAG 2.4.7
Lokasi: resources/css/app.css (Baris 44-63) & resources/views/layouts/app.blade.php (Baris 43-61)
Masalah & Dampak UX Saat Ini Aturan input, textarea, select, button { outline: none !important; } menghapus fokus bawaan browser, tetapi pengganti box-shadow oranye hanya diberikan pada input/textarea/select. Pengguna keyboard (tombol Tab) tidak dapat melihat tombol mana yang sedang fokus.
Rekomendasi Perbaikan Senior UI/UX Tambahkan aturan global button:focus-visible, a:focus-visible { outline: 2px solid #f97316 !important; outline-offset: 2px !important; } agar cincin fokus muncul khusus saat navigasi keyboard tanpa mengganggu klik mouse.
[UX-03] Penggunaan Native Browser alert() dan Gaya Terkunci pada Menu Tahapan Mahasiswa yang Sudah Selesai
HIGH • Interaction & Flow
Lokasi: resources/views/layouts/app.blade.php (Baris 381-428)
Masalah & Dampak UX Saat Ini Tahapan mahasiswa yang sudah selesai (Pengajuan Judul, Sempro, Sidang) menggunakan onclick="alert('Anda sudah melakukan...'); return false;" dengan gaya redup text-slate-600 opacity-50 cursor-not-allowed sehingga tampak seperti fitur rusak/error.
Rekomendasi Perbaikan Senior UI/UX Tampilkan indikator ceklis hijau semantik (bg-emerald-500/20 text-emerald-400 dengan ikon ✓) untuk memberikan sense of progress, dan arahkan klik ke halaman detail/riwayat atau tampilkan <x-toast> non-blocking.
[UX-04] Penggunaan Emoji Unicode Sebagai Ikon Struktural Antarmuka
MEDIUM • Visual Consistency
Lokasi: resources/views/dashboard.blade.php (Baris 94-247) & resources/views/layouts/app.blade.php (Baris 1054-1056)
Masalah & Dampak UX Saat Ini Penggunaan emoji 🎂 di dalam kotak ikon w-10 h-10 rounded-xl bg-rose-500 serta 📅 dan 📍 pada kartu notifikasi jadwal melanggar aturan SIBIMA Design System Pasal 1 (emoji tampil beda di tiap OS).
Rekomendasi Perbaikan Senior UI/UX Ganti seluruh emoji pada komponen struktural dengan ikon SVG monokromatik Heroicons/Lucide (ikon calendar, map-pin, dan cake / sparkles).
[UX-05] Penggunaan Ukuran Font Mikro (text-[9px] dan text-[10px]) Berlebihan dengan Letter-Spacing Ekstrem
MEDIUM • Typography & Legibility
Lokasi: resources/views/components/status-badge.blade.php (Baris 24), layouts/app.blade.php (Baris 306, 319), dashboard.blade.php
Masalah & Dampak UX Saat Ini Ukuran default <x-status-badge> adalah text-[9px] (9 piksel) dengan font-black uppercase, serta label grup sidebar memakai text-[10px] tracking-[0.4em]. Pada layar Windows 1080p standar, teks 9px mengalami sub-pixel blurring dan sulit dibaca oleh dosen senior.
Rekomendasi Perbaikan Senior UI/UX Naikkan batas bawah ukuran teks badge pada status-badge.blade.php dari text-[9px] menjadi text-[11px] (11px), dan perhalus tracking-[0.4em] menjadi tracking-[0.18em].
[UX-06] Tombol Berbasis Ikon (Icon-Only Buttons) Belum Dilengkapi Atribut aria-label dan aria-expanded
MEDIUM • Screen Reader ARIA
Lokasi: resources/views/layouts/app.blade.php (Baris 310, 894, 925, 931, 1162), components/toast.blade.php (Baris 65), auth/login.blade.php (Baris 59)
Masalah & Dampak UX Saat Ini Tombol hamburger mobile, tutup sidebar, toggle dark mode, lonceng notifikasi, logout, dan tutup toast hanya berisi elemen <svg> tanpa aria-label sehingga terbaca sebagai "unlabelled button" oleh pembaca layar.
Rekomendasi Perbaikan Senior UI/UX Tambahkan atribut aria-label deskriptif dalam Bahasa Indonesia pada seluruh tombol ikon, :aria-expanded pada dropdown, serta aria-hidden="true" pada SVG dekoratif.
[UX-07] Animasi Berkelanjutan (animate-pulse pada Alert & Confetti) Belum Menghormati prefers-reduced-motion
MEDIUM • Motion Ergonomics
Lokasi: resources/views/seminar_schedules/index.blade.php (Baris 10), dashboard.blade.php (Baris 125-235), resources/css/app.css
Masalah & Dampak UX Saat Ini Alert session('success') di halaman jadwal menggunakan class animate-pulse pada seluruh kotak hijau sehingga berkedip tanpa henti dan mendistraksi fokus baca pengguna.
Rekomendasi Perbaikan Senior UI/UX Hapus animate-pulse dari kontainer utama banner alert sukses, dan tambahkan media query @media (prefers-reduced-motion: reduce) di app.css serta pengecekan pada kanvas confetti.
[UX-08] Artificial Skeleton Delay (150ms) dan Kepadatan View pada Halaman Daftar Skripsi/Bimbingan
MEDIUM • Perceived Performance
Lokasi: resources/views/theses/index.blade.php (Baris 8-16; total 2.507 baris)
Masalah & Dampak UX Saat Ini State pageLoading: true yang ditahan dengan setTimeout(() => pageLoading = false, 150) membuat tabel yang sebenarnya sudah dirender oleh server berkedip menampilkan skeleton setiap kali halaman dibuka.
Rekomendasi Perbaikan Senior UI/UX Inisialisasi pageLoading: false saat halaman selesai dimuat, dan hanya aktifkan pageLoading = true ketika pengguna memilih/mengirimkan filter baru (saat menunggu respons jaringan).
[UX-09] Inkonsistensi Komponen Empty State (<x-empty-state> vs Markup Manual)
LOW • Component Reuse
Lokasi: resources/views/components/empty-state.blade.php (Baris 1-40) & seminar_schedules/index.blade.php (Baris 414-432)
Masalah & Dampak UX Saat Ini Komponen <x-empty-state> menggunakan deskripsi uppercase tracking-widest font-black dan belum mendukung slot tombol aksi (seperti tombol Reset Filter Pencarian).
Rekomendasi Perbaikan Senior UI/UX Tambahkan dukungan $slot pada <x-empty-state> untuk tombol Call-to-Action dan ubah deskripsi ke kalimat normal (text-xs font-medium text-slate-500).
[UX-10] Duplikasi Aturan CSS Global Antara resources/css/app.css dan Inline <style> pada Layout
LOW • CSS Architecture
Lokasi: resources/css/app.css (Baris 24-133) & resources/views/layouts/app.blade.php (Baris 34-93)
Masalah & Dampak UX Saat Ini Aturan CSS untuk focus ring oranye dan WebKit autofill ditulis ganda di app.css dan di dalam tag <style> pada layouts/app.blade.php.
Rekomendasi Perbaikan Senior UI/UX Konsolidasikan seluruh aturan global ke resources/css/app.css sebagai Single Source of Truth dan sisakan hanya aturan [x-cloak] di inline head.

6. Analisis Pengalaman Pengguna Berdasarkan Peran (Role-Based UX Journey)

4 Peran Pengguna

Peran Mahasiswa

Kekuatan: Stepper tahapan akademik di sidebar & konfirmasi hadir 1-klik di lonceng notifikasi.
Solusi Peningkatan: Ganti alert() pada tahapan selesai (UX-03) dengan lencana ceklis hijau ✓ Selesai.

Peran Dosen (Pembimbing & Penguji)

Kekuatan: Filter "Hanya Jadwal Saya" dan penanda peran otomatis di setiap sesi.
Solusi Peningkatan: Naikkan font badge 9px ke 11px (UX-05) dan hilangkan kedipan skeleton 150ms (UX-08).

Peran Kaprodi & Admin Akademik

Kekuatan: 2-Tier Header Toolbar dengan tinggi kontrol seragam 40px dan counter antrean real-time.
Solusi Peningkatan: Aktifkan cincin fokus :focus-visible keyboard pada seluruh tombol aksi tabel (UX-02).
