# Git Commit & Push Workflow

Setiap kali menyelesaikan tugas, perbaikan, atau perubahan kode di repositori ini, SELALU lakukan:
1. `git add` file-file yang telah diubah atau dibuat.
2. `git commit -m "..."` dengan pesan commit deskriptif mengikuti format conventional commits (contoh: `feat: ...`, `fix: ...`, `refactor: ...`).
3. `git push origin <branch>` ke remote branch aktif (biasanya `main`).
